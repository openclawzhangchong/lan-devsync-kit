## 3. app.ini 关键配置

完整模板见 `install\app.ini.template`。隐私与稳定相关的关键项：

```ini
[repository]
ROOT = E:/devsync/gitea-repos
DEFAULT_PRIVATE = private          ; 新仓库默认私有
[server]
HTTP_PORT = 3300                   ; 3000 被 zcode-hub 占用
ROOT_URL = http://192.168.168.199:3300/
DISABLE_SSH = true                 ; 全走 HTTP，免配 SSH
OFFLINE_MODE = true                ; 不打外部服务
[security]
INSTALL_LOCK = true                ; 跳过网页安装向导
SECRET_KEY = <64位hex>             ; 存于 E:\devsync\gitea\custom\conf\secret.key
[service]
DISABLE_REGISTRATION = true        ; 禁止任何人自行注册
SHOW_REGISTRATION_BUTTON = false
[database]
DB_TYPE = sqlite3                  ; 免装数据库服务
SQLITE_JOURNAL_MODE = WAL
[log]
MODE = file                        ; 文件日志，日切+8MB轮转
```

初始化命令：`gitea.exe migrate --config custom/conf/app.ini`（自动建 SQLite 库）。

## 4. 管理员账号

```bash
gitea.exe admin user create --config ... --admin --username dev --password <随机16位> \
  --email dev@local.lan --must-change-password=false
```

- 凭据落盘：`E:\devsync\secrets\gitea-admin.txt`（仅本机，勿提交）
- CLI 专用令牌：API `POST /api/v1/users/dev/tokens`，name=`devsync-cli`，scope=`write:repository, write:user`，备份在 `E:\devsync\secrets\devsync-cli-token.txt`

## 5. 服务注册（NSSM）与防火墙

```bash
nssm install DevSyncGitea E:\devsync\gitea\gitea.exe
nssm set DevSyncGitea AppParameters "web --config E:\devsync\gitea\custom\conf\app.ini"
nssm set DevSyncGitea AppDirectory E:\devsync\gitea
nssm set DevSyncGitea AppStdout E:\devsync\logs\gitea-service.out.log
nssm set DevSyncGitea AppStderr E:\devsync\logs\gitea-service.err.log
nssm set DevSyncGitea Start SERVICE_AUTO_START
```

防火墙（需要提权，本机走静默提权脚本 `tools\elevate-setup.ps1`）：

```bash
netsh advfirewall firewall add rule name="DevSync Gitea 3300" dir=in action=allow \
  protocol=TCP localport=3300 remoteip=192.168.168.0/24,127.0.0.1
```

**只放行本网段与回环**，其他来源（含跨网段/公网）默认拒绝。

## 6. 踩坑实录（照抄能避开）

| 坑 | 现象 | 解法 |
|---|---|---|
| PowerShell 5.1 读无 BOM 的 UTF-8 脚本 | 含中文的 .ps1 解析报错/乱码 | 全部 .ps1 加 **UTF-8 BOM**；需要提权执行的脚本干脆纯 ASCII |
| 嵌套引号（bash→powershell→Start-Process→powershell） | 静默失败无任何输出 | 全部改成**文件传参**（`-File xxx.ps1`），消灭内联命令 |
| UAC 过滤令牌 | 管理员账号 `net session` 仍拒绝访问 | 检测 `ConsentPromptBehaviorAdmin=0` 后走 `Start-Process -Verb RunAs` 静默提权 |
| NSSM 输出全是 NUL 字节 | bash 管道看不到结果 | `| tr -d '\0'` |
| `sc start` 报 5 拒绝访问 | 非提权 shell | 静默提权脚本内 Start-Service |
