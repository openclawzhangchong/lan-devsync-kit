# 03 · 接入指南 · 其他电脑

> 给"机器B / 机器C"。前提：枢纽机已部署并开机（http://192.168.168.199:3300 能打开）。

## 步骤（每台电脑约 2 分钟）

### 1. 装 Git for Windows（如果还没有）

https://git-scm.com/download/win 默认选项即可。

### 2. 生成自己的令牌（在枢纽网页上，不是命令行）

1. 浏览器打开 http://192.168.168.199:3300
2. 用 `dev` 登录（密码问枢纽机主，或看枢纽机 `E:\devsync\secrets\gitea-admin.txt`；登录后建议改密码）
3. 右上角头像 → **设置 → 应用 → 生成新令牌**
4. 权限勾选 **repository（读写）**，生成后**复制那串令牌（只显示一次）**

### 3. 一键接入

把本仓库的 `install\` 目录拷到该电脑（U 盘 / 任何方式），然后：

```powershell
powershell -ExecutionPolicy Bypass -File install\install-another-pc.ps1
# 按提示：粘贴令牌 → 自动完成 安装devsync + 加PATH + 存令牌(DPAPI加密) + 体检
```

也可以一步带全参数（适合自动化）：

```powershell
powershell -ExecutionPolicy Bypass -File install\install-another-pc.ps1 `
  -Hub http://192.168.168.199:3300 -User dev -Token <你的令牌>
```

### 4. 验证

```bash
devsync doctor      # 应全绿
devsync open        # 能打开枢纽网页
```

## 接入后第一件事：把项目接过来

```bash
devsync clone demo-app        # 克隆枢纽上已有的项目
# 或者这台机器上已有本地项目要接入：
cd E:\你的项目\foo
devsync init                  # 自动在枢纽建同名私库并首次推送
```

## 常见问题

- **克隆时弹用户名密码框**：令牌没写进凭据管理器。重跑一次 `devsync setup -Hub http://192.168.168.199:3300 -User dev -Token <令牌>`。
- **枢纽连不上**：先在枢纽机上确认服务在跑（`sc query DevSyncGitea`）、枢纽机没关机；再确认这台电脑和枢纽在同一网段（192.168.168.x）。
- **令牌弄丢了**：在枢纽网页 设置→应用 里删掉旧的重新生成，再跑一次 setup。
- **想换枢纽机**：见 [部署手册](02-部署手册-枢纽机.md) 重新安装，然后把各电脑 `devsync setup -Hub 新地址` 重配即可，仓库数据整体拷贝 `E:\devsync\gitea-repos` 与 `E:\devsync\gitea\data`。
